## 💡 项目简介

**Free Display** 是一款通用、轻量级、低延迟的开源无线显示接收端软件。  
项目起源于对闲置 Android 设备硬件算力的深度挖掘，通过优化底层硬件解码管线、Wi-Fi Direct P2P 点对点传输与网络流媒体解包协议，将普通设备转变为专业级低延迟无线副屏。

架构具备高度通用性，广泛兼容各类 Android 手机、平板及智能显示终端。

---

## 🚀 核心特性

- 🖥️ **电脑无线扩展 / 镜像**：支持作为电脑的无线扩展显示器或镜像屏，最高支持 60fps 高帧率硬件直通低延迟解码。
- 📱 **移动端无线投屏**：兼容标准 Wi-Fi Display (Miracast)，支持手机屏幕镜像与电脑桌面模式大屏扩展。
- 👆 **反向触控精准映射**：内置 UIBC 触控通道与模拟输入接口，零漂移视口黑边消除，指哪打哪。
- ⚡ **快速热点与直连**：内置 2.4GHz 快速热点与相机扫码极速互联，无路由器环境亦可流畅投屏。
- 🎛️ **悬浮控制抽屉**：轻触唤出，无操作 5 秒自动缩回轻量悬浮把手，支持多档画质切换与 4 种画面缩放模式。
- 🔄 **自动在线更新**：集成 GitHub Releases 在线静默检测与一键极速下载，新版本自动提醒。

## 🛠️ 构建与编译

本项目基于 Gradle 构建，采用 GitHub Actions 实现全自动 CI/CD。

### 本地编译
```bash
# 赋予 gradlew 执行权限
chmod +x gradlew

# 编译 Free Display 安装包
./gradlew :freedisplay:assembleDebug
```

编译产物位于：
- `freedisplay/build/outputs/apk/debug/freedisplay-debug.apk`
